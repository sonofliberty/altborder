# Flag sources

- ISO country and territory flags, including Kosovo: `flag-icons` 7.5.0, MIT license. See `LICENSE-flag-icons.txt`.
- Northern Cyprus: based on the public-domain Wikimedia Commons file `Flag of the Turkish Republic of Northern Cyprus.svg`.
- Somaliland: based on the Wikimedia Commons file `Flag of Somaliland.svg`, sourced there from the Government of Somaliland.
- `neutral.svg` is an original AltBorder placeholder graphic.
